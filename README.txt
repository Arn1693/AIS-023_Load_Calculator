AIS-023 LOAD CALCULATOR - INSTALLABLE APP
=========================================

UPLOAD
1. Upload this whole folder (index.html, manifest.webmanifest, sw.js, icons/)
   to your website, e.g.  https://yourwebsite.com/ais023/
2. The site must use HTTPS (padlock in the address bar). Phones will not
   install the app over plain http.
3. Keep the files together in the same folder. Do not rename them.

INSTALL ON A PHONE
- Android (Chrome): open the link and tap "Install app" at the top,
  or Chrome menu (three dots) > Install app / Add to Home screen.
- iPhone (Safari): open the link, tap Share > Add to Home Screen.
- Desktop (Chrome/Edge): an install icon appears in the address bar.

UPDATING
Replace index.html on the website. Installed phones get the new version the
next time they open the app with internet. If you change the icons, also change
CACHE = 'ais023-v1' in sw.js to 'ais023-v2' so phones refresh them.

RECORDS
Records are stored on each phone. Use Export CSV to share or back them up.
